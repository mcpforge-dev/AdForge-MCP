Политика конфиденциальности HolyMedia MCP

Дата обновления: 22 июня 2026 года

HolyMedia MCP — это B2B-сервис для подключения рекламных кабинетов, просмотра рекламных данных, анализа кампаний и работы с AI-клиентами через hosted MCP-сервер.

Эта политика объясняет, какие данные мы собираем, как используем и защищаем их, когда пользователь работает с сайтом, личным кабинетом, OAuth-подключениями Google Ads, Meta Ads и другими рекламными платформами.

1. Какие данные мы собираем

Мы можем обрабатывать следующие категории данных:

  • данные аккаунта: имя, email, настройки профиля, статус аккаунта, данные сессии;
  • данные рекламных подключений: платформа, идентификаторы рекламных аккаунтов, названия аккаунтов, выбранные пользователем аккаунты;
  • рекламные данные: кампании, статусы кампаний, бюджеты, расходы, показы, клики, конверсии и базовые метрики эффективности;
  • данные Google Ads: доступные пользователю customer accounts, кампании, статусы и базовые показатели, полученные через Google Ads API после OAuth-разрешения пользователя;
  • данные Meta Ads: доступные пользователю рекламные аккаунты, кампании, статусы и базовые показатели, полученные через Meta API после OAuth-разрешения пользователя;
  • OAuth-данные: access token и refresh token, необходимые для поддержания подключений к рекламным платформам;
  • технические данные: IP-адрес, тип браузера, диагностические события, ошибки, журналы безопасности и сведения, необходимые для защиты сервиса.

2. Как мы используем данные

Мы используем данные только для предоставления функций HolyMedia MCP:

  • создание и обслуживание личного кабинета пользователя;
  • подключение рекламных платформ через OAuth;
  • отображение подключённых рекламных аккаунтов, кампаний, статусов и базовых метрик;
  • подготовка отчётов, диагностик и безопасных предварительных просмотров действий;
  • предоставление доступа AI-клиентам, таким как Codex, Claude или ChatGPT, только после авторизации пользователя;
  • обеспечение безопасности, предотвращение злоупотреблений, исправление ошибок и поддержка сервиса.

3. Использование данных Google и Meta

HolyMedia MCP получает данные Google Ads и Meta Ads только после явного OAuth-разрешения пользователя и использует их только для функций, связанных с рекламной аналитикой и управлением подключёнными аккаунтами.

Данные Google Ads используются для вывода доступных рекламных аккаунтов, кампаний, статусов и базовых метрик. Данные Meta Ads используются для аналогичных функций внутри личного кабинета HolyMedia MCP и подключённых AI-клиентов.

Мы не продаём данные Google, Meta или других рекламных платформ. Мы не используем эти данные для скоринга, кредитования, нерелевантного профилирования или рекламы, не связанной с пользовательским запросом.

Использование и передача данных, полученных через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

4. Передача данных третьим лицам

Мы не продаём персональные данные и рекламные данные пользователей. Ограниченная передача данных возможна только в следующих случаях:

  • инфраструктурным провайдерам, необходимым для хостинга и работы сервиса;
  • рекламным платформам, когда это требуется для OAuth-авторизации или API-запросов, инициированных пользователем;
  • AI-клиентам, которые пользователь самостоятельно подключил к своему аккаунту HolyMedia MCP;
  • если это требуется законом, судебным запросом или для защиты безопасности сервиса.

5. Хранение и защита данных

Мы применяем разумные технические и организационные меры защиты:

  • HTTPS-соединения;
  • серверное хранение OAuth-подключений;
  • хеширование персональных MCP-token;
  • ограничение доступа к production-системам;
  • разделение пользовательских рабочих пространств;
  • диагностику и журналы без намеренного раскрытия секретов, токенов и паролей.

OAuth credentials, refresh tokens, client secrets, developer tokens и другие секреты не публикуются, не коммитятся в репозиторий и не показываются пользователям после сохранения.

6. Срок хранения

Мы храним данные аккаунта и рекламных подключений столько, сколько необходимо для предоставления сервиса, соблюдения требований закона, безопасности, диагностики и поддержки пользователя.

Пользователь может отключить рекламную платформу, отозвать доступ в настройках Google/Meta или запросить удаление данных аккаунта.

7. Права пользователя и удаление данных

Пользователь может запросить удаление аккаунта, отключение рекламных подключений, экспорт или уточнение данных, написав нам на email поддержки.

Для удаления данных, связанных с Google Ads или Meta Ads, пользователь также может отозвать доступ приложения в настройках соответствующей платформы.

8. Международная обработка

Данные могут обрабатываться на серверах и инфраструктуре, расположенных за пределами страны проживания пользователя. Мы принимаем разумные меры для защиты данных согласно этой политике.

9. Изменения политики

Мы можем обновлять эту политику. Если изменения существенно затрагивают обработку данных Google, Meta или персональных данных, мы обновим эту страницу и, когда требуется, запросим повторное согласие пользователя.
