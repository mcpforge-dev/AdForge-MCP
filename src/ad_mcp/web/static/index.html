    3. Быстрый сценарий для Codex

    1. Откройте Codex и перейдите в Settings / Настройки.
    2. Откройте раздел MCP / MCP Servers и нажмите “Add server”.
    3. Выберите подключение по HTTP.
    4. В поле URL вставьте адрес выше.
    5. В заголовках добавьте Authorization и значение Bearer <ваш ключ доступа>.
    6. Сохраните сервер, перезапустите MCP-подключение и откройте новый чат.

    3. Подключение Claude

    Что заполнить в Claude: укажите название и адрес HolyMedia MCP. Если Claude попросит дополнительные поля, используйте блок ниже.

    NameHolyMedia MCP
    Remote MCP server URLhttps://mcp.holymedia.kz/mcp
    OAuth Client IDоставьте пустым
    OAuth Client Secretоставьте пустым

    Важно: личный ключ доступа не вставляйте в поле OAuth Client Secret.

    Как это работает: Claude откроет вход в HolyMedia MCP, а затем получит доступ только к вашему рабочему пространству.

    Проверьте публичную страницу и получите короткий список улучшений по первому экрану, офферу, текстам, удобству, доверию и конверсии.

    Что можно улучшить на сайте

    Вставьте URL страницы. HolyMedia MCP не заходит в закрытые кабинеты и не проверяет внутренние адреса, а анализирует только публичный сайт.

    Пример для AI-клиента: “Проанализируй сайт и скажи, что мешает заявкам”. Результат будет коротким: только приоритетные рекомендации без длинного технического отчёта.
