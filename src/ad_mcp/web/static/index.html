    2. Выберите AI-клиент

    3. Быстрый сценарий для Codex

    1. Откройте Codex и перейдите в Settings / Настройки.
    2. Откройте раздел MCP / MCP Servers и нажмите “Add server”.
    3. Выберите тип подключения “Streamable HTTP”.
    4. В поле URL вставьте MCP URL выше.
    5. В Headers / Заголовки добавьте Name: Authorization, Value: Bearer <ваш ключ доступа>.
    6. Сохраните сервер, перезапустите MCP-подключение и откройте новый чат.

    3. Подключение Claude

    Что есть в Claude сейчас: форма принимает Name, Remote MCP server URL и optional OAuth Client ID/Secret.

    NameAdForge MCP
    Remote MCP server URLhttps://mcp.holymedia.kz/mcp
    OAuth Client IDоставьте пустым
    OAuth Client Secretоставьте пустым

    Важно: персональный MCP token нельзя вставлять в OAuth Client Secret. Это другое поле и другой протокол.

    Как это работает: Claude найдёт OAuth metadata, зарегистрирует client, откроет вход в AdForge MCP и получит access token через PKCE.

    Что уже работает: Claude API или другой Claude-клиент, который поддерживает remote MCP URL плюс authorization_token/Authorization: Bearer ....

    Загружаем Claude OAuth credentials...

    OAuth Client Secret будет показан только один раз Эти значения нужны только для Advanced settings в Claude. Это не personal MCP token.

    3. Подключение ChatGPT

    ChatGPT Apps/connector: для пользовательских рекламных данных нужен OAuth 2.1. Мы не будем делать no-auth endpoint и не будем просить клиента вставлять raw token в небезопасное место.

    Безопасный путь: OAuth authorization server, PKCE, scopes, revoke/rotate, audit и отдельное тестирование ChatGPT Developer Mode / Apps flow.

    Сейчас: используйте Codex, либо Claude/API-клиент с Bearer token. `/mcp` остаётся закрытым и без token отвечает 401.

    Подсказка по безопасности Если клиент показывает поле “Bearer token environment variable”, туда нельзя вставлять сам ключ. Введите имя переменной ADFORGE_MCP_CLIENT_TOKEN, а ключ сохраните в эту переменную окружения. Если ключ попал в скриншот или чат, сгенерируйте новый.
