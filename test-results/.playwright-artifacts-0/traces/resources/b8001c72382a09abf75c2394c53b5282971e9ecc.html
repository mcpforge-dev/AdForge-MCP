Безопасность

Изменения — только после подтверждения

По умолчанию HolyMedia MCP только читает данные. Любое доступное изменение сначала показывает предварительный результат и ждёт вашего подтверждения.

  • ✓
    Без передачи паролейПодключение через официальный OAuth.
  • ✓
    Контроль действийБез подтверждения ничего не меняется.
