# Спецификация отчёта

Использовать `assets/monthly-report-template.pptx` как образец структуры и визуального языка, а не как источник актуальных данных.

## Рекомендуемая структура

1. Титульный слайд: клиент, период, каналы, география.
2. Общие итоги: расход и результаты по каналам; не выводить общий CPL для несовместимых результатов.
3. Ключевые события: только подтверждённые записи журнала.
4. Meta Ads: итоги, структура кампаний, статусы и ограничения.
5. Meta Ads: креативы; агрегировать только по надёжному creative/asset ID или утверждённой карте эквивалентности.
6. Meta Ads: вовлечённость и доступные органические показатели.
7. Google Ads: итоги по типам кампаний.
8. Google Ads: группы и ключевые слова.
9. Google Ads: Auction Insights без домыслов о стратегии конкурентов.
10. Объяснение аукционных метрик при необходимости.
11. Аналитика: факты, подтверждённые причины, ограничения и неизвестные данные.
12. Рекомендации с `evidence_ids`, условиями и рисками.
13. Завершение и период отчёта.

## Обязательные элементы

- Период, timezone, валюта и окно атрибуции.
- Определения результата/лида/конверсии.
- Статус источника для бизнес-данных.
- Явная пометка `Данные не предоставлены` для существенных `UNKNOWN`.
- Реестр источников в приложении, заметках или сопроводительном JSON.
- Список ограничений, если они влияют на интерпретацию.

## Запреты

- Не переносить цифры, даты, названия кампаний и выводы из шаблона.
- Не писать причину события без подтверждённого журнала/ответа.
- Не называть креатив победителем только по минимальному CPL без минимального объёма и проверки качества.
- Не рекомендовать увеличение бюджета без учёта ограничений качества, мощности бизнеса и цели.
